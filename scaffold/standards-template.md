# Standards Template

How to align each figure to standards. The pattern below follows the verified Trial of John Brown alignment (October 2026). Alignment is per figure, verified fresh each time — never copied from another figure's document.

## Checklist

For each figure, work through in order:

1. **C3 Framework (NCSS).** Dimension 2 (History) and Dimension 4 (Communicating Conclusions). The strongest fits for encounter-style work are usually D2.His.16.9-12 (integrate evidence from multiple sources into a reasoned argument) and D4.1.9-12 (construct arguments with evidence, acknowledging counterclaims). Select only indicators the encounter genuinely exercises; quote the indicator text.
2. **Common Core ELA.** Reading in History/Social Studies (RH.9-10 / RH.11-12) and Speaking & Listening (SL). Strong fits: RH.11-12.6 (evaluate authors' differing points of view), SL.11-12.3 (evaluate a speaker's point of view, reasoning, and use of evidence and rhetoric). Verify against thecorestandards.org.
3. **Home state first.** Align to Charles's state standards for the figure's era and subject (the Trial used South Carolina USHC). Then add the states where the figure's content is most likely taught.
4. **Other states.** Add quick hits for large-adoption states (Texas, Florida, California, New York) with the specific anchor codes.

## Verification discipline

- **Verify against official documents**, not aggregators, wherever retrievable. Name the source for each framework.
- **Note what you could not verify.** If the official document wasn't directly retrievable, say so and name what you verified against instead.
- **Never cite a draft as adopted.** If a proposed-but-unadopted standard mentions the figure, exclude it or label it explicitly as proposed.
- **Check the grade band.** Note where a state's anchor sits in a different grade than the encounter's target band (e.g., Texas places Civil War content in Grade 8 while the encounter targets 9–12).
- **Date the verification.** Standards get revised. Every alignment document carries the date it was verified.

## Output

One file per figure: `figures/{{slug}}/standards-alignment.md`, following the structure of the Trial's alignment document — framework sections with indicator codes and full text, grade band stated up front, verification caveats at the end. The teacher instructions carry a condensed version.
