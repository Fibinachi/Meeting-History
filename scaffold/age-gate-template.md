# Age-Gate Template

> **PROPOSED — NOT APPROVED.** This design has not been authorized. Do not build a student version from it until Charles approves the threshold and the approach.

## The proposed design

A student version of each figure prompt — for solo, unsupervised use — with the tutorial asking the student's age before the figure speaks. The figure never asks; the modern guide does.

- **Under 16:** restrained detail. All facts preserved — what happened, to whom, how many times, with or without consent, with or without anesthesia — but close anatomical or sexual description is omitted. Nothing true is removed; nothing is softened into a different story.
- **16 and over:** full historical detail, as in the teacher version.

The proposed threshold is **under 16 restrained / 16+ full**. Charles has not approved this threshold.

## Rules for the restrained register

1. **Facts are never removed, only undescribed.** "He operated on her thirty times without anesthesia" stays. The clinical particulars go.
2. **The vocabulary discipline holds.** The figure's period words stay; the restraint is in what gets depicted, not in how the figure talks.
3. **The closing question is unchanged.** The judgment the student is asked to render does not get easier.
4. **The solo debrief addresses the student directly** ("you met...") rather than assuming a classroom discussion to follow.

## What still needs deciding

- The age threshold itself.
- Whether the solo student version is authorized at all (the library is currently built for supervised use).
- Whether age is asked once per session or per figure.
- How the model verifies age (it can't — this is an honor system, and the template should say so honestly).
